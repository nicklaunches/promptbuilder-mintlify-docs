Prompt Library is where you store, organize, and reuse the prompts you create across Prompt Builder.

It has two tabs:

- **My Prompts** — your saved prompts (from Generator, Optimizer, or Tester)
- **Community Prompts** — prompts shared by others, which you can copy into My Prompts

## Find prompts fast

Use search and three filters to narrow the list:

- **Search** — by title, description, or prompt text
- **Categories** — by prompt type: Standard, Research, Writing, Planning, Agent, Code
- **Tags** — your own free-form labels (the list is built from tags already in use)
- **Models** — by target model (Universal, ChatGPT, Claude, Gemini, and more)

Filters combine, and a **Clear filters** action appears when any are active.

## How prompts are organized

Every saved prompt carries metadata so it's easy to find later:

- **Category** — the prompt type
- **Tags** — free-form labels you choose
- **Models** — the target model(s) it's written for
- Plus title, description, and the prompt text

When you **Edit** a prompt you can update all of these — title, description, prompt text, category, tags, and models. Pinned prompts always sort to the top.

## My Prompts

My Prompts is your personal prompt workspace.

<AccordionGroup>
  <Accordion title="Pin / unpin">
    Pin your best prompts so they stay at the top of the list.
  </Accordion>
  <Accordion title="Edit">
    Update the title, prompt, description, category, tags, and models.
  </Accordion>
  <Accordion title="Delete">
    Remove prompts you no longer need.
  </Accordion>
  <Accordion title="Run">
    Start a **new** Tester chat seeded with the prompt.
  </Accordion>
  <Accordion title="Import">
    Bring in prompts in bulk from the **Import** action.
  </Accordion>
</AccordionGroup>

## Community Prompts

Browse prompts shared by the community and **Add to Library** to copy one into My Prompts, where you can adapt and re-save it.

<Tip>
  A great workflow: add a community prompt → adapt it to your needs → save your edited version (with your own tags and models) to My Prompts.
</Tip>

## Recommended workflow

<Steps>
  <Step title="Create or import">
    Start from:
    - Prompt Generator (idea → first draft)
    - Prompt Optimizer (rewrite an existing prompt)
    - Community Prompts (copy a template)
  </Step>

  <Step title="Refine">
    Iterate in Prompt Tester until the prompt reliably produces the result you want.
  </Step>

  <Step title="Save, tag + pin">
    Save the final prompt to My Prompts, add a category, tags, and models so it's easy to filter, and pin it if it's a frequent workflow.
  </Step>
</Steps>
