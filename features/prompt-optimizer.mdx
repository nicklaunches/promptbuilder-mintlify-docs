Prompt Optimizer takes a prompt you already use, analyzes it, asks up to three quick questions, and rebuilds it stronger.

> Paste a prompt you already use. Prompt Builder will analyze it, ask up to three quick questions, and rebuild it stronger.

## When to use it

Use Prompt Optimizer when you already have a prompt and want to:

- Improve clarity and structure
- Add constraints and acceptance criteria
- Make the output format explicit (JSON, table, checklist)
- Turn a loose ask into a stronger, reusable instruction set

## The composer

Optimizer uses the same composer as the Generator:

- **Prompt type** — defaults to **Auto**; Prompt Builder resolves the right type from the prompt you paste.
- **Model** — the target model for the rewrite. Defaults to **Universal**.
- **Voice**, **Attach**, and **Instructions** — dictate, add context files, and apply your standing rules. See [Instructions](/features/instructions).
- **Optimize** — analyze and rebuild the prompt.

## How optimization works

<Steps>
  <Step title="Paste your prompt">
    Drop in the prompt you want to improve (or insert one from your [Library](/features/prompt-library)). Set a prompt type and model, or leave them on Auto / Universal.
  </Step>

  <Step title="Answer a few quick questions">
    Prompt Builder analyzes the prompt and may ask **up to three quick questions** to fill in missing context (audience, format, constraints). Pick from the suggested answers or add your own, then continue.
  </Step>

  <Step title="Get the rebuilt prompt">
    Prompt Builder rewrites the prompt and opens it in the prompt view, ready to copy, refine, or save.
  </Step>
</Steps>

<Note>
  The optimized prompt is written in the same language as the prompt you paste.
</Note>

## After you optimize — what's next?

The rebuilt prompt opens in the same prompt view as the Generator, with the same next steps:

<CardGroup cols={2}>
  <Card title="Create follow up prompt">
    Spin up a related prompt seeded from this one.
  </Card>
  <Card title="Improve your prompt">
    Answer a few questions to sharpen the prompt even further.
  </Card>
</CardGroup>

From there you can copy the prompt, keep refining, or **Save** it to your Library. Each optimization is kept in your recent history so you can revisit earlier versions.

## Tips for best results

- Prefer concrete inputs: include examples, edge cases, and "don't do" constraints.
- If you need a strict format, say so (and include a schema).
- Use short follow-up optimizations instead of one massive rewrite.
